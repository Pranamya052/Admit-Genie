Admit Genie – AI-Powered Admission Assistant Chatbot

Admit Genie is an AI-powered admission assistant chatbot designed to help students access admission-related information quickly and easily. The platform uses Retrieval-Augmented Generation (RAG) to retrieve relevant information and generate context-aware responses.

The application helps students with admission guidance, eligibility queries, application procedures, important dates, and frequently asked questions through an interactive conversational interface.

🎯 Core Features

Admission Query Assistance

Provides instant answers to student admission-related questions using an AI-powered conversational interface.

RAG-Based Retrieval

Retrieves relevant information from the knowledge base before generating responses, improving the relevance and accuracy of answers.

Intelligent Response Generation

Uses Google Gemma to generate context-aware responses based on the retrieved information.

Interactive User Experience

Provides a simple and user-friendly chat interface built with Streamlit for seamless interaction.
